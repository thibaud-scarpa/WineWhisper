# WineWhisper
WineWhisper est une app iPhone de gestion de cave à vin : on y ajoute ses bouteilles en scannant l'étiquette, on les retrouve dans une vue 3D de ses caves, on suit le moment où chaque vin est à son apogée, et un sommelier intégré choisit la bonne bouteille selon le plat ou l'occasion.
